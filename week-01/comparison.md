## 4. What the AI Got Wrong or Silently Skipped

Rocket initially displayed the average score using only one decimal place instead of two.

**Input:** 50, 49.5, 100, 0

**Expected average:** 49.88

**Actual average:** 49.9

The application performed the calculation but did not follow the required output precision.

## 5. The Defect I Asked Rocket to Fix

**Prompt I used:**

Fix the average score formatting. The average must always display exactly two decimal places, rounded correctly. For the marks 50, 49.5, 100, 0, display 49.88 instead of 49.9. Keep all other calculations unchanged.

**Result:** Fixed.

Rocket changed `toFixed(1)` to `toFixed(2)` in `StatsBentoGrid.tsx`.

After the fix, the application correctly displayed 49.88. The other displayed statistics remained correct in the follow-up test.

**What this tells me:**

AI-generated software can contain small but important defects. Developers must verify results against precise requirements instead of assuming that a working application is completely correct.

## 6. Reflection (200–300 words)

In this practice, I compared two approaches to developing a student marks analysis program: a Python console program and an AI-generated web application built with Rocket.new. The experiment helped me understand the advantages and limitations of AI-assisted software development.

Rocket significantly accelerated the creation of a complete user interface. After I entered a short prompt and answered a clarification question, it generated a dashboard using Next.js and TypeScript. The application included additional features such as a pass threshold slider, median calculation, and visual statistics. Creating these features manually would require additional development time and knowledge.

However, the AI-generated application was not completely correct. During an additional test with the marks 50, 49.5, 100, and 0, I discovered that Rocket displayed the average as 49.9 instead of 49.88. The problem was caused by incorrect decimal formatting. I submitted a follow-up prompt, and Rocket fixed the issue by changing the formatting from one decimal place to two.

The Python version was simpler and easier to inspect because it used basic programming concepts and had fewer components. I used ChatGPT assistance for its implementation, so I cannot describe that code as independently written. I would be more comfortable submitting a version after personally reviewing every line and verifying all required test cases.

This experiment showed me that software engineers remain responsible for requirements, testing, correctness, and understanding the generated code. AI can accelerate development, but it cannot replace careful human verification and accountability.
